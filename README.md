# RBLX Презентации — конструктор слайдов

Сайт-презентация с конструктором в стиле Canva. День 1.

## Что умеет

- **2 стартовых слайда**: «Регистрация в Roblox» и «Roblox Studio»
- **Редактирование текста**: двойной клик по тексту прямо на слайде, плюс панель свойств (размер, цвет, жирный/курсив, шрифт, выравнивание, прозрачность)
- **2 стиля оформления**: ⚡ Неон и ◈ Жидкое стекло (эстетика iOS: blur, скругления, светлые градиенты) — палитра текста автоматически адаптируется под тему
- **Фотографии**: загрузка с диска, перетаскивание файлов на слайд, замена, скругление, изменение ширины
- **✨ Удаление фона** — алгоритм flood-fill от краёв снимка с настройкой чувствительности и сглаживанием краёв (без внешних API, всё локально в браузере)
- **Конструктор как в Canva**: перетаскивание элементов, ресайз за угол, дублирование, слои (вперёд/назад), блоки-подложки
- **Слайды**: добавление, дублирование, удаление, миниатюры, фоны-градиенты на выбор
- **Режим презентации** (кнопка ▶ или F5): стрелки/пробел для навигации, Esc — выход
- **✏️ Редактирование прямо в презентации**: кнопка ✏️ в панели управления — выбор элементов, перетаскивание, двойной клик по тексту, удаление/дублирование, панель свойств и добавление фото работают поверх слайда; слайд автоматически вписывается между панелями
- **Экспорт / импорт проекта** в JSON, автосохранение в localStorage

## Запуск

```bash
python3 -m http.server 8000
# открыть http://localhost:8000
```

## Структура

```
index.html        — разметка приложения
css/style.css     — обе темы (неон / жидкое стекло)
js/state.js       — данные: project → slides[] → elements[] (схема v2), фабрики, миграция v1
js/storage.js     — автосохранение localStorage (rblx-pres-v2, миграция из rblx-pres-v1)
js/render.js      — отрисовка: сцена, миниатюры, презентация, тулбар, тосты
js/editor.js      — редактирование: выбор, правка, drag/resize, CRUD, свойства, темы, презентация, удаление фона
js/export.js      — экспорт / импорт / сброс проекта (JSON)
js/app.js         — точка входа: загрузка → тема → отрисовка → инициализация
assets/img/       — иллюстрации для демо-слайдов
```

## Данные (схема v2)

```json
{
  "version": 2,
  "theme": "neon",
  "slides": [
    {
      "id": "…", "bg": "",
      "elements": [
        { "id": "…", "type": "text|image|block",
          "x": 60, "y": 46, "w": 720, "h": 78,
          "rotation": 0, "zIndex": 0,
          "props": { "text": "…", "fontSize": 58, "…": "…" } }
      ]
    }
  ]
}
```

Геометрия (`x, y, w, h, rotation, zIndex`) — на уровне элемента, всё содержимое — в `props`.
Старые сохранения (rblx-pres-v1, плоские элементы) мигрируют автоматически при загрузке.

## Архитектура: один вход изменения

```js
App.setState(mutator)   // мутация → App.render.renderAll() → App.storage.save()
```

Любое изменение состояния проходит только через `setState()` (см. `js/state.js`).
Перерисовка обновляет узлы сцены/презентации на месте, если структура слайда не
изменилась — поэтому рендер безопасен во время кликов и жестов. Исключение —
«живой предпросмотр» внутри жеста (перетаскивание, слайдеры, ввод текста): он
пишет прямо в узел и модель, а коммит жеста идёт через `setState()`.
